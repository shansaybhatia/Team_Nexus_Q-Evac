## Project Summary

**Q-Evac** is a quantum-powered evacuation planning system designed to improve disaster response worldwide.

The system helps emergency agencies:

- Optimize evacuation routes
- Assign shelters efficiently
- Allocate rescue vehicles
- Reduce traffic congestion

Q-Evac models disaster evacuation as an optimization problem using:

**QUBO (Quadratic Unconstrained Binary Optimization)**

Quantum optimization can evaluate many evacuation plans simultaneously, enabling faster decision-making during emergencies.

The system is designed for **neutral atom quantum processors** such as those developed by Infleqtion.

## How It Works

**Input Data**

- Road networks
